# Examples

Examples will use synthetic, sanitized, or explicitly redistributable content only.

The [synthetic semiconductor engineering dataset v0.1](synthetic_dataset_v0_1/) is a fully synthetic public test set. It contains RunRecord scenarios and original document fixtures for software validation, local retrieval evaluation, and education.

Planned and existing examples include:

- a normal synthetic run;
- a run with missing fields;
- a malformed input;
- a run with alarm/event markers;
- a deterministic local retrieval demo over the synthetic document set.

Do not upload customer data, real fab logs, proprietary process information, private platform exports, credentials, or unredacted screenshots.

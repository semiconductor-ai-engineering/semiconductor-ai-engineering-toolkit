# Changelog

All notable project changes are recorded here. This project is pre-alpha and does not claim production readiness.

## 0.1.0-alpha.2 — Unreleased

### Added

- Phase 0.6 deterministic synthetic log parser prototype.
- Phase 0.7 deterministic engineering report generator.
- Phase 0.8 local-only knowledge retrieval demo.
- Phase 0.9 retrieval evaluation harness with deterministic metrics.
- README public-launch status update reflecting the completed Phase 0.6–0.9 workflow foundation.

## 0.1.0-alpha.1 — Unreleased

### Added

- Public semiconductor engineering data model documentation.
- RunRecord v0.1 JSON Schema as the canonical data contract.
- Deterministic Python schema validation API and `semi-ai validate` CLI.
- Fully synthetic semiconductor engineering dataset v0.1 with RunRecord and document fixtures.
- CI tests, package build verification, and release-readiness workflow preparation.
- Explicit security, synthetic-only, and data-isolation boundaries.

### Limitations

- The toolkit does not control semiconductor equipment, modify recipes, or provide process safety guidance.
- It does not diagnose real fab failures, connect to HDP/private systems, execute AI agents, perform RAG, or parse arbitrary vendor logs.
- Synthetic values, units, event codes, documents, and relationships are for software testing, evaluation, and education only. They are not real process windows, equipment behavior, recipe limits, safety rules, or root-cause evidence.
- No GitHub Release, version tag, or PyPI publication is created by this phase.
